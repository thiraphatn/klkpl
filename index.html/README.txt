ฟาร์มสุขใจ - PWA Farm Game

ไฟล์หลัก:
- index.html
- style.css
- app.js
- manifest.json
- sw.js

วิธีใช้งาน:
1. แตกไฟล์ ZIP
2. เปิดผ่านเว็บเซิร์ฟเวอร์ (แนะนำ VS Code + Live Server หรือ GitHub Pages)
3. เปิดบนมือถือด้วย Chrome/Edge
4. เมื่อรองรับ PWA จะมีปุ่ม "ติดตั้งแอป"

หมายเหตุ: Service Worker และ PWA ต้องรันผ่าน HTTPS หรือ localhost จึงจะทำงานได้เต็มรูปแบบ
เกมบันทึกเงิน เมล็ด ผัก และของตกแต่งไว้ใน localStorage ของเบราว์เซอร์

อัปเดต: ระยะการเจริญเติบโตของพืช
- แครอท 3 ระยะ (3+5+7 = 15 วินาที)
- ข้าวโพด 4 ระยะ (4+6+7+8 = 25 วินาที)
- มะเขือเทศ 4 ระยะ (5+8+10+12 = 35 วินาที)
- ฟักทอง 5 ระยะ (6+8+10+12+14 = 50 วินาที)
แตะแปลงที่กำลังโตเพื่อดูรายละเอียดแต่ละระยะ แก้เวลาได้ที่ตัวแปร crops ใน app.js (ค่า t หน่วยวินาที)

อัปเดต: ระบบธีมตกแต่งฟาร์ม
- ของตกแต่งไม่ได้วางในแปลงผักอีกต่อไป แต่เป็น "ธีม" ที่ตกแต่งรอบๆ แปลง (บน ล่าง ซ้าย ขวา) พร้อมเอฟเฟกต์เคลื่อนไหว
- 12 ธีม: ทุ่งหญ้าสดใส(ฟรี), สวนซากุระ, ฟาร์มไทยริมคลอง, ฟาร์มริมทะเล, ทุ่งหิมะ, ฤดูใบไม้ร่วง, ฮาโลวีน, คริสต์มาส, โอเอซิสทะเลทราย, ป่าเวทมนตร์, ฟาร์มบนดาวอังคาร, ฟาร์มราชสำนัก
- ซื้อแล้วสลับใช้ได้ตลอด สีดินของแปลงเปลี่ยนตามธีมด้วย
- เซฟเก่าที่มีของตกแต่งในแปลงจะถูกเอาออกและคืนเงินให้อัตโนมัติ
- เพิ่มธีมใหม่ได้ที่ตัวแปร themes ใน app.js

อัปเดต: พืชหลากหลาย + เสียงประกอบธีม
- พืช 16 ชนิด ราคาเมล็ดตั้งแต่ 1, 2, 5, 10, 15, 20, 25, 30, 45, 60, 80, 100, 120, 150, 175 ไปจนถึง 200 💰
  แต่ละชนิดมีจำนวนระยะและเวลาเจริญเติบโตต่างกัน (แก้ได้ที่ตัวแปร crops ใน app.js)
- ร้านเมล็ดมีตัวกรองตามช่วงราคา และปุ่มซื้อ ×5
- เสียงบรรยากาศแยกตามธีม สังเคราะห์ด้วย Web Audio (audio.js) ไม่ต้องมีไฟล์เสียง ใช้ออฟไลน์ได้
  ปุ่ม 🔊 มุมขวาบนใช้เปิด/ปิดเสียง (เบราว์เซอร์จะเริ่มเล่นเสียงหลังการแตะครั้งแรก)
- เสียงเอฟเฟกต์: ปลูก เก็บเกี่ยว พืชพร้อมเก็บ ซื้อ เงินไม่พอ
